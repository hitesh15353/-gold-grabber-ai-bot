# GoldGrabber AI Bot

Telegram gold/XAUUSD news intelligence MVP.

## Render
Create a **Background Worker** from this repository/ZIP.
Set these Environment Variables:
- TELEGRAM_BOT_TOKEN
- OPENAI_API_KEY
- NEWS_API_KEY

Never put secret keys in source code.

## Commands
/start
/news
/gold
/why
/full

This MVP provides news-driven decision support, not guaranteed trading predictions.
